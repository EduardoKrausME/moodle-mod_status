# mod_status - Meu status

Atividade Moodle simples para aulas práticas. O professor define os estados disponíveis e cada estudante mantém um único estado atual, por exemplo:

- Ainda não comecei
- Trabalhando
- Preciso de ajuda
- Terminei

O professor recebe um painel ao vivo com os estudantes agrupados por estado e uma coluna adicional para quem ainda não marcou nada. O painel é atualizado automaticamente a cada cinco segundos.

## Requisitos

Moodle 4.5 ou superior.

## Instalação

Copie a pasta `status` para `mod/status` e conclua a atualização pelo administrador do Moodle.
